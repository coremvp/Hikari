## Build on the included paths

Signup opens Dashboard immediately. Account holds subscription controls. The server checks the Supabase session before serving protected pages and checks persisted subscription state before granting subscriber access.

Docs and Blog use local MDX with Fumadocs. You can change the content, sidebar, and landing page in the same repository as your application. Read [Project structure](/docs/getting-started/project-structure) to find the right edit point.

## When to consider CoreMVP

Hikari is free MIT source for individual accounts, recurring subscriptions, Docs and Blog. You run, customize and operate it with your own providers. CoreMVP is a premium startup application foundation delivered as source code, adding shared Organizations with invitations and roles, persisted Projects, and lifetime/one-time payments with guest checkout.

If those collaboration or payment paths fit your product, explore the [CoreMVP Next.js product](https://coremvp.com/en/products/nextjs) and [CoreMVP demo](https://nextjs.coremvp.com). The Product page owns current commercial terms. Start with Hikari’s local account when its included scope is sufficient; neither product includes hosting.
